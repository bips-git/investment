# Reading a Factsheet

<Badge type="tip" text="Beginner" /> <Badge type="info" text="8 min read" />

::: info 🎯 What you will learn
- What a mutual fund factsheet is and why it matters
- How to read the benchmark, riskometer and portfolio sections
- What rolling returns are and why they matter more than a single-year return
- Which commonly seen numbers, like star ratings, deserve less weight
:::

## In plain words

Think of a factsheet like a school report card. A report card does not just show one
exam's marks; it shows subjects studied, attendance, and marks across different terms, so
you get a fuller picture of a student's actual performance. A mutual fund **factsheet**
gives a similar fuller picture of a scheme, beyond just one headline return number.

## How it works

### What a factsheet is

A **factsheet** - a document, usually published monthly by an AMC, summarising a mutual
fund scheme's objective, holdings, performance, costs, and risk level.

### Benchmark

A **benchmark** - the index or standard a scheme compares its own performance against,
usually an index matching the scheme's category, introduced in Unit 3.2. For example, a
large-cap equity fund might use the Nifty 50 as its benchmark.

Always check a scheme's returns against its own stated benchmark, not against a different
category's index or a different scheme entirely.

### Riskometer

A **riskometer** - a SEBI-mandated visual scale on every factsheet, showing a scheme's
risk level, ranging typically from "Low" to "Very High", based on the scheme's holdings
and category.

::: warning 📅 Check the latest
The riskometer's exact categories and calculation methodology are set by SEBI and can be
updated over time. Confirm the current riskometer framework on SEBI's website if you need
precise details.
:::

### Portfolio

The **portfolio** section lists the actual stocks, bonds, or other instruments the scheme
currently holds, usually with their percentage weight in the scheme.

1. Check the top holdings to understand what the scheme is actually invested in.
2. Check sector or industry concentration, to see if the scheme is heavily weighted toward
   one sector.
3. Compare the portfolio against the scheme's stated category and objective, to confirm
   they match.

### Rolling returns

**Rolling returns** - returns calculated over many overlapping periods of the same length
(for example, every possible 5-year period within the available data), rather than a
single fixed period. Rolling returns give a fuller picture of consistency than one
point-to-point return figure.

| Return type | What it shows |
|---|---|
| Point-to-point return | Return between two specific fixed dates only |
| Rolling return | Return across many overlapping periods, showing a range of outcomes |

A single point-to-point return can look unusually good or bad depending on the exact start
and end dates chosen. Rolling returns reduce this sensitivity to the specific dates picked.

### What to weigh less heavily

| Commonly seen figure | Why it deserves less weight alone |
|---|---|
| Star ratings | Often based mainly on past returns, which do not guarantee future performance |
| Short-term returns (a few months or one year) | Can be heavily influenced by short-term market swings, not the fund's underlying strategy |
| A single point-to-point return | May not reflect performance consistency across different periods |

::: tip 💡 Real-life example
Deepa is comparing two equity funds using their factsheets.

| Item checked | Fund A | Fund B |
|---|---|---|
| Benchmark | Nifty 50 | Nifty 50 |
| Riskometer | Very High | Very High |
| 1-year point-to-point return | 22% | 14% |
| 5-year rolling return range | 9% to 13% across periods | 10% to 12% across periods |
| Expense ratio (see Unit 3.3) | 1.6% | 0.9% |

All figures are illustrative, not a forecast. Fund A looks better on the recent 1-year
number alone, but Fund B has shown a more consistent rolling return range and a lower
expense ratio. This shows why relying on one short-term number alone can be misleading.
:::

::: warning ⚠️ Common mistakes
- Comparing a scheme's return to a different category's benchmark, rather than its own.
- Relying on a single year's return, or a star rating, as the main decision factor.
- Ignoring the riskometer, and being surprised later by a scheme's actual volatility.
- Not checking whether the portfolio matches the scheme's stated category and objective.
:::

::: danger 🚨 Safety check
Past returns shown in any factsheet, however impressive, do not guarantee future
performance. Any promotional material implying guaranteed future returns based on past
performance is a warning sign, covered further in Chapter 9.
:::

::: details 🧠 Go deeper (university level)
NISM workbooks and standard portfolio management texts, including Prasanna Chandra's
*Investment Analysis and Portfolio Management*, emphasise that performance should always be
evaluated relative to a matching benchmark and over multiple rolling periods, since a
single point-to-point return is highly sensitive to the exact start and end dates chosen,
a statistical issue sometimes called "data snooping" or "cherry-picking" when done
deliberately to make performance appear better than it consistently is.
:::

## Quick recap

- A factsheet summarises a scheme's objective, holdings, performance, costs and risk.
- Always compare a scheme's return against its own stated benchmark.
- The riskometer shows a SEBI-mandated risk level; the portfolio shows actual holdings.
- Rolling returns give a fuller, less date-sensitive picture than a single point-to-point
  return.
- Star ratings and short-term returns deserve less weight than consistent rolling
  performance and cost.

## Check yourself

1. Why should you compare a scheme's return only against its own stated benchmark?
   ::: details Show answer
   Different benchmarks represent different markets or segments. Comparing against a
   mismatched benchmark can make performance look better or worse than it really is,
   relative to a fair comparison.
   :::
2. What does the riskometer on a factsheet show?
   ::: details Show answer
   A SEBI-mandated visual scale showing a scheme's risk level, from Low to Very High, based
   on its holdings and category.
   :::
3. Why do rolling returns give a fuller picture than a single point-to-point return?
   ::: details Show answer
   Rolling returns are calculated across many overlapping periods, reducing sensitivity to
   the exact start and end dates chosen, unlike a single point-to-point figure.
   :::
4. Why should a high star rating alone not be the main reason to choose a fund?
   ::: details Show answer
   Star ratings are often based mainly on past returns, which do not guarantee future
   performance, and may not reflect cost, risk, or consistency in the same depth as a full
   factsheet review.
   :::
