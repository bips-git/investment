# Measuring Returns

<Badge type="tip" text="Beginner" /> <Badge type="info" text="8 min read" />

::: info 🎯 What you will learn
- What absolute return means, and its main limitation
- What CAGR is, and when it is used
- What XIRR is, and why it suits SIP investments
- Why different apps can show different return numbers for the same investment
:::

## In plain words

Think of two students: one finished a project in one week, another took a whole year to
finish an identical project. If both projects earned the same final marks, simply
comparing final marks alone hides an important difference: how long each one took. Return
measures work the same way; some account for time, and some do not.

## How it works

### Absolute return

**Absolute return** - the total percentage gain or loss on an investment, from the start
to the end of a period, without accounting for how long that period was.

```
absolute return = (current value - amount invested) / amount invested x 100
```

| Item | Value (illustrative) |
|---|---|
| Amount invested | ₹1,00,000 |
| Current value | ₹1,30,000 |
| Absolute return | 30% |

This is illustrative, not a forecast. Absolute return does not reveal whether this 30% was
earned in 1 year or in 10 years, which makes it unsuitable for comparing investments held
for different lengths of time.

### CAGR

**CAGR** (Compound Annual Growth Rate) - the constant yearly compound growth rate that
would take an investment from its starting value to its ending value, over a stated
number of years, assuming steady annual growth.

```
CAGR = (ending value / starting value) ^ (1 / number of years) - 1
```

| Item | Value (illustrative) |
|---|---|
| Starting value | ₹1,00,000 |
| Ending value | ₹1,30,000 |
| Number of years | 3 |
| Approximate CAGR | 9.1% per year |

This is illustrative, not a forecast. CAGR is useful for a single lumpsum investment held
over a known number of years, since it expresses the outcome as an annualised rate,
connecting back to the compounding concept in Unit 1.2.

### XIRR

**XIRR** (Extended Internal Rate of Return) - a return measure that accounts for multiple
cash flows happening on different, irregular dates, such as a series of SIP installments,
each with its own date and amount.

CAGR assumes a single starting amount and a single ending amount. A SIP involves many
separate investments made on different dates, so a single CAGR figure does not fit well.
XIRR solves this by calculating the single annualised rate that makes all the cash flows
(each installment, and the final value) consistent with each other.

| Return measure | Best suited for |
|---|---|
| Absolute return | A quick, simple gain or loss check, without comparing across time periods |
| CAGR | A single lumpsum investment, held over a known number of years |
| XIRR | Multiple investments on different dates, such as a SIP, STP, or irregular additions and withdrawals |

::: warning 📅 Check the latest
Exact XIRR calculation conventions can vary slightly between platforms, based on how they
handle the exact date of each cash flow. If precise figures matter, cross-check the
underlying cash flow dates and amounts directly against your RTA statement, introduced in
Unit 2.2.
:::

### Why apps show different numbers

1. One app might show absolute return, while another shows XIRR, for the same SIP
   investment, leading to very different-looking percentages.
2. Apps may calculate returns as of different dates, even a day's difference in NAV can
   change the shown figure.
3. Some apps include only invested capital in the calculation, while others may include
   additional cash flows like dividend reinvestment or partial withdrawals differently.
4. Rounding and data refresh timing can cause small differences even between two apps using
   the same underlying method.

::: tip 💡 Real-life example
Ketan has been running a SIP for exactly 3 years and checks his returns on two different
apps on the same day.

| App | Return measure shown | Displayed return (illustrative) |
|---|---|---|
| App A | Absolute return | 22% |
| App B | XIRR | 9.8% per year |

Both numbers can be correct at the same time; they are simply measuring different things.
The 22% is the total gain over the entire 3-year period, without accounting for time. The
9.8% is the annualised rate accounting for the fact that each installment was invested for
a different length of time. This is illustrative, not a forecast.
:::

::: warning ⚠️ Common mistakes
- Comparing an absolute return shown on one app with a CAGR or XIRR shown on another, as if
  they were the same measure.
- Assuming a high absolute return automatically means a high annualised rate, without
  checking the time period involved.
- Using CAGR for a SIP investment, which does not fit CAGR's single lumpsum assumption
  well.
- Ignoring that returns figures are usually shown before taxes, covered in Chapter 8.
:::

::: danger 🚨 Safety check
Be cautious of any promotional material that highlights only a large absolute return
figure, without stating the time period or the return measure used. This can make a
modest annualised return look far more impressive than it actually is.
:::

::: details 🧠 Go deeper (university level)
NISM workbooks describe XIRR as based on the same underlying mathematics as the Internal
Rate of Return (IRR) concept used in corporate finance, covered in texts such as Brealey
and Myers's *Principles of Corporate Finance*, extended to handle cash flows on irregular,
real calendar dates rather than assuming equally spaced periods. This is precisely why
XIRR, rather than a simple CAGR, is the standard measure recommended by AMFI and used by
most platforms for SIP and other multi-cash-flow investment reporting.
:::

## Quick recap

- Absolute return shows total gain or loss, without accounting for how long the period was.
- CAGR expresses a single lumpsum investment's growth as a constant annual rate.
- XIRR accounts for multiple cash flows on different dates, such as SIP installments.
- Different apps can show different, equally correct numbers, because they use different
  return measures or calculation dates.
- Always check which return measure is being shown before comparing figures across apps.

## Check yourself

1. What is the main limitation of absolute return as a measure?
   ::: details Show answer
   It does not account for how long the investment was held, making it unsuitable for
   comparing investments held over different time periods.
   :::
2. Why is CAGR not well suited to measuring SIP returns?
   ::: details Show answer
   CAGR assumes a single starting amount and a single ending amount, but a SIP involves
   multiple separate investments made on different dates, which CAGR does not account for.
   :::
3. What problem does XIRR solve that CAGR cannot?
   ::: details Show answer
   XIRR accounts for multiple cash flows happening on different, irregular dates, such as
   SIP installments, calculating a single annualised rate consistent with all of them.
   :::
4. If two apps show very different return percentages for the same SIP on the same day,
   what is a likely explanation?
   ::: details Show answer
   The apps are likely using different return measures, such as absolute return versus
   XIRR, which measure different things and are not directly comparable.
   :::
